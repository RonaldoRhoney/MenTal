# MENTAL — Discovery (índice)

Status: rascunho para aprovação de Rhoney. Nenhum código foi escrito a partir
deste pacote — Discovery é só entendimento e proposta.

## Fonte

Todo o conteúdo deste pacote deriva dos 4 documentos aprovados na raiz do
projeto (`MENTAL_KICKOFF.md`, `BRAND.md`, `FAMILY_SAFETY.md`,
`MONETIZATION.md`). Nada aqui contradiz o que já está aprovado — este pacote
expande os temas que o kickoff (Seção 9.3) pediu para cobrir na Discovery:
VISION, PRODUCT_PRINCIPLES, CORE_LOOP, GAMEPLAY, TERRITORIES, GAMIFICATION,
RANKING, HINT_ENGINE, ADAPTIVE_DIFFICULTY.

## Documentos deste pacote

1. [VISION.md](VISION.md) — problema, objetivo, público, proposta de valor.
2. [PRODUCT_PRINCIPLES.md](PRODUCT_PRINCIPLES.md) — princípios de produto e
   de design que orientam toda decisão futura (inclui o Princípio de Clareza
   Imediata do kickoff).
3. [CORE_LOOP.md](CORE_LOOP.md) — o laço central de jogo, sessão a sessão.
4. [GAMEPLAY.md](GAMEPLAY.md) — os 4 tipos de desafio do V1 e suas regras.
5. [TERRITORIES.md](TERRITORIES.md) — metáfora de território, mapeamento
   free/pago, condições de conquista.
6. [GAMIFICATION.md](GAMIFICATION.md) — XP, níveis, streak, conquistas,
   compartilhamento.
7. [RANKING.md](RANKING.md) — ranking geral e de amigos.
8. [HINT_ENGINE.md](HINT_ENGINE.md) — sistema de dicas progressivas.
9. [ADAPTIVE_DIFFICULTY.md](ADAPTIVE_DIFFICULTY.md) — como a dificuldade se
   adapta ao jogador.
10. [RISKS_AND_OPEN_DECISIONS.md](RISKS_AND_OPEN_DECISIONS.md) — riscos e
    decisões pendentes que precisam de aprovação explícita de Rhoney antes da
    Foundation.

## O que este pacote não é

- Não é arquitetura técnica (isso é `01_FOUNDATION/ARCHITECTURE.md`, etapa
  seguinte, só depois de aprovação).
- Não é modelo de dados nem contrato de API.
- Não define valores finais (preço de assinatura, número exato de
  territórios, limite diário) onde o material de origem já sinalizou "a
  validar com Rhoney" — esses pontos ficam listados em
  `RISKS_AND_OPEN_DECISIONS.md`.
