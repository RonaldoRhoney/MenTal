# FOUNDATION

Documentos cross-cutting — valem pra todas as versões do MENTAL, não são
escopo de uma versão específica. Atualizados conforme necessário, não
"fecham" numa entrega.

- `MENTAL_KICKOFF.md` — kickoff oficial do produto.
- `BRAND.md` — identidade de marca.
- `DESIGN_SYSTEM.md` — tokens visuais, tipografia, componentes.
- `MONETIZATION.md` + `MONETIZATION_UPDATE_FREE_LAUNCH.md` — modelo de monetização.
- `FAMILY_SAFETY.md` — políticas de segurança (histórico multi-geracional, hoje superado pela DIR-001).
- `USER_PROFILE.md` — campos de perfil, visibilidade pública, moderação de foto.
- `MICROINTERACTIONS.md`, `AUDIO_FEEDBACK.md`, `NOTIFICATIONS.md` — camadas de feedback do produto.
- `ADMIN_PANEL_E_CREDITO_INSTITUCIONAL.md` — painel administrativo.
- `ARCHITECTURE_UPDATE_I18N_READY.md` — atualização de `docs/01_FOUNDATION/ARCHITECTURE.md`.
- `PRIVACY_POLICY.md` — política de privacidade (texto-fonte; versão hospedada em `store_assets/mental-privacidade.html`).
- `MENTAL-DIR-001_*.docx` — diretiva que tornou o MENTAL exclusivo 18+ (revoga políticas anteriores de público misto).
- `MENTAL-DIR-002_*.docx` — capa de orientação de escopo (24/08/2026), leitura prévia aos documentos POL-002/003.
- `MENTAL-POL-002_*.docx` — classificação etária e upload de imagem.
- `MENTAL-POL-003_*.docx` — política de privacidade e termos de uso (fonte formal).

A pasta `docs/` (00_DISCOVERY → 02_IMPLEMENTATION) já é a Foundation técnica
da V1 (Vertical Slice 01) — não duplicada aqui.
